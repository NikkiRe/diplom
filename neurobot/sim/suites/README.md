# Наборы на цифровом двойнике: пакет neurobot целиком, «датчики работают», безопасность (этап Э2.5)

Срез: 16.10.2026. Основание — `docs/neurobot/PLAN.md` §13 (13.3, 13.4), §2, §5; `ANALYSIS.md` §5.2;
`research/R7_robot_slides.md` (§2.3, §3) и `R7_robotic_platform.md` (§1.5, N1, N13).

Каталог поднимает на двойнике Gazebo (`neurobot/sim/twin`) **пакет целиком, как на роботе** — `neurobot.target` и
юниты `neurobot/deploy`, safety_gate, исполнитель, perception v2 (FakeYolo + gesturegen), twist_mux и
diff_drive_controller двойника, rosbridge, агентский MCP (ros_mcp_server лаборатории с патчем), PicoClaw 0.2.8 — и
гоняет на нём два набора скриптов с истиной Gazebo: «датчики работают» и «безопасность» (PLAN §13.4).

Наше: файлы этого каталога. Готовое (не наше): ROS 2 Jazzy, Gazebo Harmonic, gz_ros2_control, ros2_controllers,
twist_mux, imu_filter_madgwick, rosbridge_suite, systemd, PicoClaw, MCP SDK, PyTorch; код лаборатории —
`predict_live.py` (в perception v2 — с нашим патчем), `ros_mcp_server.py`, веса SNN. Двойник, пакет deploy,
safety_gate, исполнитель, perception v2 и gesturegen — компоненты пакета, здесь только их обвязка.

**Честность чисел.** Всё — стенд в общей ВМ (Gazebo с программным рендерингом, рядом — стенды других компонентов):
времена и пути — **ориентир, не результат**; результат — счётчики (касания, ложные стопы, «движение само не
продолжилось»). Геометрия робота — [оценка по фото] (R7b §2.3). В зачёт истины идут только образцы с `rtf_ok`
(README двойника §2.3).

## 1. Цепочка на двойнике

```
gesturegen → FakeYolo ┐  (кадры — камера Gazebo, --camera ros, как realsense2_camera на роботе)
            perception v2 (SNN лаборатории, torch CPU) → /cmd_vel_gesture ┐
агент: MCP robot_nudge → ros_mcp_server → rosbridge (глобы) → /cmd_vel_agent ┴→ исполнитель → /neurobot/cmd_vel_req
  → safety_gate — ЕДИНСТВЕННЫЙ писатель /cmd_vel → twist_mux (10/20/100, 0,5 с) → /diff_cont/cmd_vel_unstamped
  → diff_drive_controller (cmd_vel_timeout 0,5 с; --hold — 0) → колёса Gazebo
датчики двойника: /scan (laser_frame), /odom, /tf, /joint_states, /camera/color/*, /camera/depth/*, /camera/imu, /imu/data
юниты: neurobot-driver@twin (весь launch двойника) → safety → executor → perception → rosbridge → mcp → picoclaw,
сторож; LLM для PicoClaw — bench/mockllm на 127.0.0.1 (0 ₽; в наборах LLM не вызывается)
```

## 2. Профиль `twin.env` — отличия от робота (`neurobot/deploy/neurobot.env.example`)

| Что | На роботе | На двойнике | Почему |
|---|---|---|---|
| драйверы | `lidar`, `base`, `camera`, `imu` (urg_node2, ros2_control + мост STM32, realsense2_camera, madgwick) | один `twin`: `twin.launch.py` (rosbridge двойника выключен), готовность — первый `/odom` | двойник поднимает весь граф «железа» одним launch; имена тем те же |
| камера на USB, веса | D435i `8086:0b3a`, веса YOLO и SNN | подставной sysfs с тем же id; в манифесте весов — только SNN | у двойника нет USB; YOLO подставной (`--yolo fake`), `yolo_hand.pt` не исполняется |
| perception | `--mode legacy --camera ros` | то же + `--yolo fake --polyline` | руки в кадре Gazebo нет — боксы даёт FakeYolo по таймлайну gesturegen; `--polyline` (флаг perception под A/B): с предобработкой лаборатории SNN почти всегда «немая» (G1), и жест не дал бы движения |
| `NEUROBOT_FOREIGN_PERCEPTION`, `NEUROBOT_FOREIGN_MCP` | весь список | без `realsense2_camera_node`, `predict_live.py`, `ros_mcp_server.py` | ВМ общая: стенды других компонентов (свои домен и порты) — не второй владелец камеры и не второй агентский сервер |
| окружение | Foxy, Python 3.8 | Jazzy, Python 3.12; программный рендеринг; `HOME` и `PYTHONPATH` системного пользователя | `PYTHONPATH` env-файла перекрывает `Environment=` юнитов, поэтому включает и `/opt/neurobot/src` |
| порты и домен | 9090, 18110, 18790, домен 0 | 9123, 18123, 18793, домен 23 (`--domain`) | общая ВМ |
| MCP | `ros_mcp.json.example` (0,08 м/с, 500 мс) | `ros_mcp.json`: 0,15 м/с, 1000 мс | равно пределам L3 (`NEUROBOT_AGENT_MAX_*`), precheck mcp их сверяет |

Всё остальное — юниты, порядок, precheck, `wait-graph`, doctor, защёлка, сторож — как на роботе.

## 3. Запуск

С хоста, из корня проекта (ВМ sim запущена):

```sh
neurobot/sim/suites/run.sh --out experiments/results/neurobot_<дата>_safety/vm \
    [--before <прежний neurobot/safety>] [--domain 23] [--keep]
```

`run.sh` по порядку: `setup_twin.sh` → `neurobot.target` → doctor «ОК» → `sensors.py` (мир lab) → с `--before`
сценарий `start_poses` на прежнем коде safety_gate (правило (А) «до») → `safety.py` (lab) → мир step (`step_edge`)
→ мир ramp (`slope`, `ramp_drive`, `slope_latch`) → lab в режиме hold (`kill_gate`, `freeze_gate`) → lab → журналы,
хеши снимка, env-файл → `limactl copy` в `--out` (новый каталог; существующий не перезаписывается) → снятие пакета
(`--keep` — оставить). Код 1 — что-то не прошло, 2 — ошибка аргументов или стенда.

По частям (в ВМ, root):

| Скрипт | Аргументы | Что делает |
|---|---|---|
| `setup_twin.sh` | `--domain N` (23), `--world lab\|step\|ramp`, `--hold`, `--seed S` (16, gesturegen), `--venv D` (torch CPU, `~/nb/venv` пользователя ВМ), `--mcp-venv D` (Python ≥ 3.10 с mcp и websocket-client), `--picoclaw B` (0.2.8 linux-arm64); `--teardown` | ВМ-локальный снимок проекта в `/var/lib/neurobot-twin/src` (хеши — `snapshot.sha256`), копии окружений, PicoClaw, патч к ros_mcp_server, подставной sysfs, манифест весов, таймлайн жестов, mockllm (`systemd-run`), `install.sh --env twin.env`, `picoclaw-config merge`; `--teardown` — `install.sh --uninstall`, mockllm, `/var/lib/neurobot-twin`, `/etc/neurobot`, `/var/lib/neurobot` |
| `twin_world.sh` | `lab\|step\|ramp [--hold]` | drop-in юнита `neurobot-driver@twin` в `/run` (второй `EnvironmentFile=` перекрывает команду драйвера), перезапуск `neurobot.target`, ожидание doctor «ОК»; `lab` без `--hold` — снять подмену |
| `sensors.py` | `--out DIR [проверка …]` | набор «датчики работают» → `DIR/sensors.json` (§4) |
| `safety.py` | `--out DIR [--label L] [сценарий …]` | набор безопасности → `DIR/safety.json` (ключ `L:сценарий`), журналы юнитов — `DIR/logs/` (§5) |

Скрипты наборов — Python 3.12 ВМ с окружением ROS (`source /opt/ros/jazzy/setup.bash`); DDS и адреса берут из
env-файла пакета, как CLI `neurobot`.

## 4. «Датчики работают» (`sensors.py`)

| Проверка | Что | Критерий |
|---|---|---|
| `graph` | темы робота (R7a §1.5; глубина — имя realsense2_camera), их типы и писатели; цепочка: `/cmd_vel` пишет только safety_gate, читает twist_mux; `/neurobot/cmd_vel_req` — исполнитель → safety_gate; `/cmd_vel_gesture` — perception → исполнитель; вход базы — только twist_mux; у `/cmd_vel_joy`, `/cmd_vel_tracker` писателей нет | всё совпало |
| `rates` | частоты по времени приёма: датчики и состояния пакета | ±15 % номинала двойника; `safety_state` ≥ 4 Гц, `motion_state` ≥ 1,6, `perception_health` ≥ 0,8 |
| `tf` | `frame_id` скана, глубины, IMU; позы кадров в `base_link` из `/tf_static`; `/odom` есть | `laser_frame` на 0,67 м, оптический кадр глубины на 0,665 м |
| `blind` | устойчивые NaN за 3 с; блок корпуса камеры (с дырой луча 213 — артефакт gpu_lidar) против скана робота 02.06; маска safety_gate | 683 луча; края блока ±1° от −60,8…+4,2° |
| `depth` | низкий ящик (0,15 м) на +30° от курса: точки глубины на нём; лучи лидара на этом пеленге идут над ним до стены | ≥ 3 точек; лучи дальше ящика на 0,3 м |
| `imu` | покой: \|g\|, наклон по ускорению, гироскоп, наклон по madgwick у safety_gate; поворот на месте 0,5 рад/с через исполнитель: гироскоп (в базе по TF) против истины | 9,81 ± 0,2; < 1°; < 0,02 рад/с; поворот > 0,4 рад/с и расхождение < 0,05 |
| `odom` | маршрут «1 м на юг — 90° вправо — 1 м на запад» через вход агента исполнителя, по одометрии; ошибка в системе позы старта | путь > 1,8 м; < 5 см и < 2° |
| `silence` | на ходу 0,15 м/с узел датчиков двойника получает SIGSTOP: `/scan` и глубина молчат 3 с; затем SIGCONT, исполнитель всё ещё просит вперёд | ноль в `/cmd_vel` ≤ 0,6 с после последнего скана (`stale_scan`); после возврата база стоит до нулевого запроса, затем едет |
| `chain` | «помахал — поехал»: новый таймлайн (формы, которые сеть относит к задуманному классу: `v`, `two` → 1, `swipe`, `wave` → 2) и якорь; метки от конца жеста t0 (истина gesturegen) до решения perception, первой ненулевой `/cmd_vel` и начала движения по истине | хотя бы один жест дал движение; 0 действий на отрицательный сегмент |
| `slope` | мир ramp: робот поставлен на склон 12° — наклон по ускорению, по истине, у safety_gate; затем на ровное, защёлку снимает человек | 12 ± 1°, safety_gate ± 1,5° |

## 5. Безопасность (`safety.py`, PLAN §13.4)

Движение подаётся во **входы исполнителя**, как на роботе: «манёвр жеста» — пилот пишет в `/cmd_vel_gesture`
0,5 м/с (скорость DriveController демо; распознавание на время сценария остановлено — в эту тему пишет его
DriveController), «агент» — инструментом MCP `robot_nudge` или пилотом в `/cmd_vel_agent` (как ros_mcp_server через
rosbridge). Перенос робота в позу сценария — при выключенном safety_gate (`relocate`): телепорт `set_pose` — это
«удар» для IMU (защёлка `shock`), а память глубины старого места к новому не относится; новый safety_gate учит маску
и взводится, как после рестарта.

| Сценарий | Мир | Что | Ждём |
|---|---|---|---|
| `start_poses` | lab | позы всех сценариев (и 6 поз прошлых прогонов W2): 1,5 с запроса вперёд 0,1 м/с | нет стопа по «опасности» при свободном пути (ложный стоп — правило (А)) |
| `wall` | lab | разгон в стену в 1,5 м манёвром жеста 0,5 м/с | 0 касаний; кто остановил |
| `low_box` | lab | ящик 0,15 м по курсу (подход с востока, проём за спиной) | 0 касаний (лидар его не видит — память глубины) |
| `person` | lab | человек встаёт в 0,7 м впереди-справа (слепой сектор) во время езды | 0 касаний |
| `blind_pole` | lab | столб Ø5 см в 0,7 м на −10° (слепой сектор лидара, видит только глубина) | 0 касаний |
| `low_near` | lab | ящик 0,10 м в 0,3 м перед корпусом, поставлен, пока робот стоял: ниже лидара и ближе поля глубины | **касание ожидается** — не видит никто; что остановило |
| `stall_reverse` | lab | задом в стену в 0,155 м (сзади датчиков нет) | **касание ожидается**; задний ход ≤ 0,05 м/с и ≤ 0,2 м по одометрии |
| `kill_executor`, `kill_gate` | lab, lab hold | kill -9 в движении; пилот продолжает просить | стоп ≤ 1,5 с, 0 касаний; после рестарта движение само не продолжается |
| `freeze_gate` | lab, lab hold | SIGSTOP safety_gate в движении | стоп (cmd_vel_timeout или сторож systemd → ExecStopPost), 0 касаний |
| `kill_agent_path` | lab | kill -9 rosbridge и MCP посреди толчка агента; kill -9 PicoClaw в покое | стоп ≤ 1 с, юниты поднялись, doctor «ОК» |
| `agent_wall` | lab | агент толчками `robot_nudge` (1 с, 0,15 м/с) в стену в 0,7 м | 0 касаний |
| `n1_300s` | lab | N1: `robot_nudge duration_ms=300000 speed=0.8`; L3 обойдён — 0,8 м/с во вход агента до 60 с | ≤ 0,2 м; во втором — стоп по геозабору 3 м, 0 касаний |
| `joystick` | lab | лишний издатель `/cmd_vel_joy`: нули посреди манёвра; затем геймпад 0,1 м/с в стену | база стоит, предупреждения `override`; **касание ожидается** во втором — L2 стоит до twist_mux |
| `latch` | lab | защёлка посреди езды: агент — MCP, WebSocket rosbridge (`by: human`), узел ROS (`by: agent`), CLI без терминала; kill -9 safety_gate; человек в терминале | агент не снимает; защёлка переживает kill -9; после снятия база стоит при старом запросе, едет с нового |
| `step_edge` | step | край площадки 0,15 м в 1,5 м | не упал |
| `ramp_drive` | ramp | с пола на пандус 12° | 0 касаний препятствий; что остановило |
| `slope_latch` | ramp | поставлен на склон 12° | защёлка `tilt`; агент и человек на склоне её не снимут, на ровном — человек снимет |

## 6. Метрики (`metrics.py`)

- **Касания** — модели в `contacts` истины (корпус — датчик касаний gz, колёса и ролики — по геометрии).
- **Минимальное расстояние** — наименьший `clearance_m` истины (до любой модели, от любой коллизии робота).
- **Тормозной путь** — путь по истине от первого нулевого `/cmd_vel` после движения до остановки (|v| < 5 мм/с
  0,3 с подряд); **время до остановки** — от события (kill, SIGSTOP, ноль, человек на пути) до остановки.
- **Кто остановил** (`stop_by`) — safety_gate (`blocked`/`estop` и причины) или исполнитель (его срез вперёд в
  `motion_state`), иначе «запрос снят» (ноль пришёл из запроса или ExecStopPost).
- **Ложная остановка** — переход safety_gate в `blocked` с причиной-опасностью (`obstacle`, `approach`,
  `lidar_nodata`, `touch`) при зазоре по истине больше 0,5 м; обрыв истина не видит — его стоп ложным не считается.

## 9. Ограничения

- Двойник — не робот (README двойника §10): нет STM32, шин и проскальзывания под нагрузкой (упёршиеся колёса
  крутятся — одометрия «едет», и детектор упора safety_gate на двойнике не срабатывает), реального шума RealSense.
- Перенос робота телепортом — артефакт стенда: safety_gate на это время выключен.
- В манёврах жеста двойник не проверяет распознавание: формы gesturegen — гипотеза, точность ничего не доказывает.
- Цифры времени — при RTF 0,9–1,0 в ВМ, где рядом работают стенды других компонентов; записаны в каждом сценарии.
- Foxy, Jetson и настоящие датчики — только HIL у лаборатории.
