# Пульт оператора NeuroChip — режим «Запись»

Веб-пульт робота NeuroChip по `docs/ui/PLAN.md` (§0а — действующий уменьшенный объём, §4 экраны, §6 стек; этапы П0 и
П1). Пульт — **«окно, а не руль»**: в режиме «Запись» он проигрывает прогоны на цифровом двойнике и ничем не управляет.
Работает на Mac без ВМ и сети. Python ≥ 3.8, только stdlib (этот же пакет станет живым шлюзом на роботе, П2);
браузерная часть — статика без сборки и Node.

## Запуск за минуту

Из корня проекта:

```sh
python3 -m neurobot.ui serve --bundle neurobot/ui/samples/demo_hall.json.gz
# пульт (запись): http://127.0.0.1:18120/
```

Открыть `http://127.0.0.1:18120/`. В демо-бандле два прогона в зале двойника: **A0** — стек лаборатории как на роботе
(16.10) и **A1** — пакет 1 + безопасность v2 (18.10), одно расписание жестов и отказов. Пульт открывается в конце
записи — там итоговые числа, те же, что в compare.md. Кнопка ▶ — проиграть с начала, ×1 / ×10 / ×60 — скорость,
щелчок по полосе внизу — перемотка в это место (на полосе — состояния safety_gate и метки жестов).

Свой бандл из каталогов прогонов (`experiments/results/…`, в git не входят):

```sh
R=experiments/results
python3 -m neurobot.ui replay --out $R/ui_20261019_replay/bundle.json.gz --runs \
    a0=$R/neurobot_20261016_a0/vm a1v2=$R/neurobot_20261018_a1v2/vm \
    lab_v5=$R/neurobot_20261018_acceptfix2/runs/lab_v5 long_v5=$R/neurobot_20261018_acceptfix2/runs/long_v5
python3 -m neurobot.ui serve --bundle $R/ui_20261019_replay/bundle.json.gz [--port 18120]
```

`--runs` — каталоги `runner.py` (`ID=DIR` или просто `DIR`, тогда ID — метка прогона). Сборка 4 прогонов — несколько секунд.

| Клавиша, параметр | Что |
|---|---|
| `1` `2` `3`, `Esc` | экраны; `Esc` — «Обзор» |
| пробел, `←` `→` (`Shift` — по минуте) | пауза и пуск (и после щелчка по ×60), перемотка на 10 с |
| щелчок по стоящей тревоге | квитировать: гасит мигание, не тревогу; вставшая снова — мигает снова |
| «i» у заголовка панели | пояснение: откуда число и как считается (на экране — только числа) |
| `?run=a1v2&t=1095&speed=60&play=1&theme=dark#/safety` | прогон, момент от начала расписания (с; без `t` — конец записи), скорость, пуск, тема, экран |

## Экраны

Каркас на всех экранах — ровно в окно, прокручивается только рабочая область: строка состояния (состояние safety_gate
и первая причина, `v out` — в живом режиме ещё `/ предел`, тревоги «активных N · за 10 мин M» — M равно строкам ленты,
возраст данных, время записи и T от начала расписания, режим НАБЛЮДЕНИЕ, знак **ЗАПИСЬ** и «источник: запись · прогон ·
дата (двойник, мир)», кнопка «СТОП движения» — в записи неактивна, под ней видна подпись «только в живом режиме»),
навигация и лента тревог (стоящие, под чертой — снятые за 10 мин: 5 последних и «ещё N»), проигрыватель. Данных нет
дольше 2 с — рабочая область уходит в штриховку «показанное больше не правда».

| # | Экран | Что на нём |
|---|---|---|
| 1 | Обзор (L1) | слева — безопасность: сначала состояние и первая причина, зазор и `d_stop`, под ними квадратный мини-лидар по safety_state, полоса состояний 15 мин и доли ok / slow / blocked / estop за прогон (`stats.safety_share` — `metrics.travel`); под ней — события стенда и человека; справа — плитки 3×2 (заголовок, значение с единицей, одна строка контекста, спарклайн 48 px): «жест → команда» p50/p95 (последние 20, точки жестов и цель пунктиром), LLM на жест (K4; линия — такие вызовы по минутам, черточки — жесты), LLM за час (вызовы, токены, ₽ факт и оценка), память стека против бюджета 4 ГБ, юниты, касания по истине стенда (накопительно); лента жестов 15 мин и последние жесты. На 1366×768 события — рядом с жестами, экран целиком в окне |
| 2 | Безопасность и жесты (L2) | состояние крупно, причины кодом и текстом с уровнем; карточка защёлки (с какого времени, причины, `sudo neurobot estop release` и «копировать» — **кнопки «снять» нет**); скорость `req → out` (старше 2 с — «—»); зазор, `d_stop` и запас; зазор и `d_stop` за 10 мин с полосой состояний; лента жестов 10 мин (форма метки — исход) и счётчики; таблица жестов с Δрасп и Δкоманда |
| 3 | Агент и тренды (L4) | окна 15 мин / 1 ч / прогон, курсоры синхронны, значения — в подсказке у курсора: вызовы LLM по минутам и токены накопительно (вызовы «на жест» — квадратами-контурами), задержка t0 → `/cmd_vel` (точки — жесты, входящие в K1) с p50/p95 последних 20 и целями K1 p95 ≤ 0,5 с и Э2 p50 ≤ 0,7 с (подписи — справа от графика, цветом своего ряда), PSS и под ним CPU стека, полоса safety_state, A0 и A1 на одной оси расписания; справа — «до/после» A0 против выбранного A1: четыре числа «до → после» (K1 p95, касания, LLM на жест, K7) и ячейки compare.md (длинные — в две строки, целиком в подсказке); реплики агенту |

Мини-лидар: скана в записях нет, поэтому рисуется сводка safety_state — корпус Ø0,39 м и коридор 0,49 м, поле лидара
±119,9° (сзади датчика нет — штриховка), маска корпуса камеры, клин глубины 87°, зазор `min_clearance_m` (пунктир,
при тревоге — её цветом поверх тёмной подложки) и тормозной путь `d_stop(v)` при скорости `/cmd_vel` не старше 2 с
(черта поперёк коридора). У A0 safety_gate нет — только корпус и подпись: защиты, которой нет, пульт не рисует.

Стиль — high-performance HMI по ISA-101 (U4 §1, §7): серое, цвет только у стоящих тревог (снятая — тот же знак
контуром, без цвета), приоритет — цветом и формой с цифрой, на полосе состояний — ещё и высотой (P1 — во всю высоту,
P2 — на две трети); акцент — только выбор и A1 («наш стек»); плоско, без анимаций. Числа моноширинным JetBrains Mono,
`tabular-nums`, запятая в дробях (и в текстах причин safety_gate), «—» вместо отсутствующего (и без единицы), число и
единица не рвутся переносом; у значения — возраст, устаревшее штрихуется. Подписи 12 px, значения 13–18 px, KPI
24–30 px; 11 px — только деления осей. Светлая и тёмная тема (токены CSS из U4 §7.2, по `prefers-color-scheme` или
переключателю внизу навигации). Экран 1920×1080 — основной, 1366×768 — минимум.

## Тревоги — два уровня (PLAN §0а п. 2; словарь — проект, утверждает студент)

| Уровень | Знак | Коды |
|---|---|---|
| P1 | красный квадрат «1» | защёлка и полный отказ: `estop`, `tilt`, `shock`, `stall`, `foreign_writer`, `lidar_fault`; пульт: `ui_safety_silent` (safety_state молчит) |
| P2 | оранжевый треугольник «2» | `stale_scan|odom|imu|accel|depth`, `scan_foreign`, `scan_publishers`, `motion_time`, `override_active`; при `blocked`/`estop`: `obstacle`, `cliff`, `approach`, `lidar_nodata`, `touch`; всегда: `geofence`, `reverse_limit`, `override`, `mask_outside`; пульт: `ui_unit_down:<юнит>`, `ui_camera_lost`, `ui_perception_recovering`, `ui_llm_open`; неизвестный код safety_gate — тоже P2 |
| норма | серый | `slow` с `lidar_blind` / `lidar_unseen` (на роботе это обычное рабочее состояние), `lidar_unknown`, `lidar_mask` (старт), `unarmed` |

Тревоги ведёт шлюз (здесь — сборщик записи) одним кодом `alarms.AlarmTracker`, браузер только рисует: повтор той же
причины — счётчик «×N» той же строки; снятие — после 3 с без причины (запись safety_state — 1 Гц, причины мерцают);
конец «компонент не работает» и «safety_state молчит» известен точно — снимаются сразу. Скрытия тревог нет;
мигает (1 Гц, без мигания при `prefers-reduced-motion`) стоящая неквитированная тревога; квитирование — по случаю
(ключ и момент, когда встала): вставшая снова мигает снова, у другого прогона — своё. Словарь сверяется тестом со
списком причин в README safety.

## Формат потока `neurobot-ui/1`

Один для «Записи» и будущего живого шлюза: сообщение — объект JSON `{"k": вид, "t": стенные часы робота, с, …}`.
«Запись» кладёт список сообщений прогона в бандл, отсортированный по `t`. Браузер не знает, откуда сообщения, кроме
подписи источника. `stream.check` проверяет вид, поля и их типы и значения (числа конечные, перечисления — `state`,
`level` 0–2, `prio` 1–2, `topic`, `outcome`…; лишнее поле — ошибка: формат один для двух концов).

**Подключение (живой шлюз, П2; описано и проверено уже в `/1`).** Шлюз шлёт сообщения по SSE `/api/stream` — одно
событие `id: <номер>` + `data: <json>` на сообщение, `hb` раз в 1 с, `retry` — и держит кольцевой буфер последних
15 мин (`stream.BUFFER_S` — самое длинное окно «Обзора»); вытесненные из буфера сообщения он скармливает
`stream.State`. Новое подключение (`stream.connect`):

1. `hello` — `format`, `source`, `active`: тревоги, стоящие в момент hello (`key`, `code`, `prio`, `text`, `n`,
   `since`, `src`); у `hello` номера нет;
2. снимок `State` на начало буфера, с исходными `t`, по возрастанию: последнее сообщение каждого вида состояния
   (`safety`, `health`, `k1`, `stats`, `mem`, `units`, `touch`; `cmd` — по каждому `topic`), стоящие тревоги
   (`alarm` с `t` = с какого момента стоит), незакрытые жесты — одним `gesture` со всеми полями, включая `kind`
   (`t` — первое сообщение жеста);
3. буфер целиком, затем живой хвост.

Браузер переподключается сам (EventSource) и шлёт `Last-Event-ID`: номер ещё в буфере — `hello` с `resume: true` и
только пропущенное, без снимка; номера в буфере уже нет — как новое подключение. Так клиент, подключившийся в любой
момент, видит те же стоящие тревоги, начатые жесты и последние значения, что клиент, видевший поток с начала
(`test_ui_stream.ConnectTest`: в зеркале Timeline на Python и в самом `timeline.js` через node). Окна трендов длиннее
буфера (1 ч, прогон) — по агрегатам `stats` (одна точка в 10 с, PLAN §0а п. 6).

| `k` | Поля | Откуда в записи / в живом режиме |
|---|---|---|
| `hello` | `format`, `source` (робот \| двойник \| запись); `run`, `mode`, `geometry`, `alarms`, `active`, `resume` | заголовок соединения (в бандле — заголовок бандла и `meta` прогона) |
| `hb` | — | живой режим: раз в 1 с |
| `safety` | `state`, `reasons`, `level` (0 норма, 1, 2); `min_clearance_m`, `estop{engaged, since, reasons}`; в живом — ещё `warnings`, `front_m`, `limits`, `req`, `out`, `cut`, `tilt_deg`, `lidar_mask_deg` | `safety.jsonl` (≈1 Гц: состояние, причины, зазор) / `/neurobot/safety_state` |
| `cmd` | `topic` (`req` — `/neurobot/cmd_vel_req`, `out` — `/cmd_vel`, `base`), `v`, `w`; `d_stop_m` | серии `events.jsonl` наблюдателя: при изменении (шаг 0,01) и раз в 1 с, пока писатель жив |
| `health` | `state`; `fps`, `frame_age_s`, `recoveries`, `dark` | `/neurobot/perception_health`: при изменении и раз в 5 с |
| `gesture` | `id`; частично: `name`, `cls`, `conf`, `margin`, `n_boxes`, `side`, `t_end`, `t_rec`, `d_rec_s` → `d_cmd_s`, `t_cmd`, `maneuver` → `outcome` (`done`, `wrong`, `none`, `cut`, `preempted`, `unobserved`, `false_action`), `stopped_by`; `expected`, `early`, `rtf_ok` (жест входит в K1 по RTF — правило `metrics.latency`), `ref` (`t0` — истина двойника, `t_end` — робот) | наблюдатель `gestures.jsonl` + `/neurobot/gesture` / `gesture`, первая команда, `events` |
| `k1` | `last`, `run` (`{n, p50, p95, max}`); `window` (20), `ref` | `metrics.latency` по жестам до момента t |
| `llm` | `kind` (`request`, `service`, `gesture` — K4); `model`, токены, `rub_fact`, `rub_est`, `latency_ms` | журнал mockllm (вызовы системы — по имени модели, как `metrics.py`) / EdgeCtx или учётный прокси |
| `agent` | `n`, `request`, `ok`; `latency_s`, `llm_calls`, `outcome` | `run.json` (реплики в канал pico) |
| `mem` | `total_mib` (без драйверов двойника); `units`, `cpu_pct` | сэмплер `collect.jsonl`, 10 с / sysmon |
| `units` | `up`, `total`; `down` | сэмплер и окна отказов / `systemctl show` |
| `fault`, `operator`, `touch` | отказ стенда с TTR; действие человека; касание по истине Gazebo | `run.json`, `truth.jsonl` (только стенд) |
| `alarm` | `key`, `code`, `prio`, `on`, `text`; `n`, `src` | `AlarmTracker` |
| `stats` | `distance_m`, `moving_s`, `moving_share`, `safety_share`, `touches`, `llm{gesture, request, service, rub_est}`, `k1` — только то, чего браузер не сосчитает сам по сообщениям (исходы жестов и токены он видит) | функции `metrics.py` по префиксу записи, раз в 10 с (PLAN §0а: тренды — одна точка в 10 с) |
| `end` | `reason` | конец записи |

Бандл `neurobot-ui-bundle/1` — JSON или `.json.gz`: `geometry` (из `neurobot.safety.config.Params`: корпус,
коридор, пределы, параметры тормозного пути; бюджеты памяти), `alarms` (словарь), `compare_rows` (строки «до/после»
с целями и короткими названиями) и `runs`: `meta` прогона (`id`, `label`, `system`, `source: запись`,
`origin: двойник`, `world`, `date` — по часам лаборатории, МСК, `dir` — от корня репозитория, `t_start`, `t_end`,
`anchor_t` — начало расписания), `summary` (`metrics` — те же ключи, что `metrics.summarize`; `compare` — ячейки),
`stream`. Времени сборки и путей машины в бандле нет: одинаковый вход — одинаковые байты, из любого каталога (тест).

## Откуда числа

- **Не считаются заново.** K1 p50/p95 без ранних, касания, вызовы LLM на жест, доли ok/slow/blocked/estop, пробег,
  реакции, память — функции `neurobot/sim/runs/metrics.py`; ячейки «до/после» — форматтеры `compare.py`. Тесты
  сверяют ячейки бандла с compare.md (`neurobot_20261018_a1v2`, `acceptfix2`, столбцы A0, A1 18.10, A1 итог), итог
  потока — с `metrics.summarize`. В конце записи пульт показывает те же числа, что compare.md.
- **K1 от t0** — истины генератора жестов на двойнике; на роботе t0 нет, будет Δ «конец жеста по perception →
  команда» (`ref: t_end`), подпись это говорит. Точки K1 на графиках — те же жесты, что в `metrics.latency`: без
  ранних (реакция раньше t0) и без жестов при RTF < 0,95 (флаги `early`, `rtf_ok`; тест: их число равно `n`).
- **Причины safety_gate** сборщик (и шлюз) переводит в «запятую в дробях» один раз — `fmt.reason`, код не трогается.
- **Чего в записях нет — «—»:** скана (лидар рисует только сводку safety_state), пределов `limits`, `front_m`,
  наклона; `req → out` — из серий наблюдателя. У A0 нет safety_gate, `/neurobot/gesture` и исполнителя: экран так и
  пишет.
- **₽:** факт — 0 (mockllm, денег нет), оценка — замороженный прайс RouterAI 06.10.2026 (`bench/costmodel`).
- Тормозной путь `d_stop(v) = v·t_lat + v²/(2·a_brake) + margin` — `neurobot.safety.motion.stop_distance` с
  умолчаниями safety_gate: допущение до замера на роботе.
- Всё — стенд в общей ВМ: ориентир, не результат робота.

## Раздача и безопасность

`serve` слушает только `127.0.0.1` (или `::1`), отдаёт только GET и HEAD: `/` и статику `web/`, `/api/bundle`
(gzip), `/api/meta`. Host — локальное имя с любым портом (туннель SSH), Origin — нет или тот же; иначе 403 (DNS
rebinding). CSP без `unsafe-inline`: единственный встроенный скрипт — import map, по хешу. При старте файлы `vendor/`
сверяются с `SHA256SUMS` — не сошлось, пульт не стартует. Никаких CDN во время работы.
