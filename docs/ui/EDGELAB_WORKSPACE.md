# EdgeLab — исследовательское рабочее пространство

20.10.2026. Развитие Edge Atlas в ветке `codex/neurochip-interface`.

## Сквозная работа

1. **Атлас сигналов / 4.** Подключить локальный MCP-источник, выбрать устройство, открыть «Прибор устройства». Поля и вложенные структуры доступны независимо от известности имени прибора. Структурные виды: число, логическое состояние, вектор, облако XY, вручную выбранная позиция XY, изображение, аудио, JSON. Единицы и система координат требуют контракта источника; пользовательские привязки хранятся в браузере. Координаты XY не выдаются за калиброванную 3D-сцену.
2. **Зафиксировать эпизод.** Полученные числовые/логические наблюдения из ограниченной истории MCP становятся отдельной трассой лаборатории. Последние структурные значения добавляются однократно с собственным временем. Отсутствующие значения остаются пропусками. История не порождает вымышленных вызовов или контекста агента. Камера имеет отдельный перенос кадра; непрерывный видеорекордер здесь не заявляется.
3. **Лаборатория / 5 → Наблюдение.** Выбрать прогон и момент на пятидорожечной ленте. Три масштаба показывают весь прогон, эпизод до 60 с и деталь до 10 с. Есть переход по событиям, скорости 1/4/16× и повтор выбранного диапазона. При наличии истинного seeded-сценария он отделён от принятых агентом входов. Вторая область показывает только реально записанный входной контекст выбранного запроса; без снимка доступна явно названная реконструкция.
4. **Решения.** Проследить ссылки input → wake/suppress → request/response → tool/result. Связь существует только по записанному идентификатору. Размеры сегментов промпта подписаны как оценки. Первичная запись доступна рядом.
5. **Эксперименты.** Выбрать шум/короткий перегрев, устойчивый перегрев или протечку; настроить gate/heartbeat/hybrid, порог температуры комнаты, debounce, период, длительность, политику и окно истории контекста. Выполняются настоящий Go EdgeCtx, локальный sim-mcp, mock-LLM и реплеер по виртуальным часам. Каждый запуск начинает сценарий заново в изолированном каталоге. A/B проверяет хеш одинаковых входов и показывает своевременные реакции, пропуски, вызовы, оценки токенов, задержки и доступные ресурсы.
6. **Инструменты.** Собрать упорядоченную цепочку: исходный сигнал → причинное среднее → производная → порог с выдержкой → разность совместимых сигналов. Есть настройки разрывов и возраста второго отсчёта. Несовместимые единицы/часы блокируют разность. Графики источника и результата позволяют перейти к отсчёту. Рецепт сохраняется и переносится JSON.
7. **Журнал.** Зафиксировать выбранное событие или результат обработки, добавить собственный вывод. Карточка хранит время, конфигурацию, исходную запись, хеш источника и рецепт. Сохранение в браузере происходит до перехода между разделами. Доступны перенос JSON и самостоятельные HTML/Markdown отчёты; удаление карточки можно отменить. Полную исходную трассу можно отдельно экспортировать JSONL и импортировать без потери оригинальных полей.

## Живая трасса работающего агента

```sh
python3 -m neurobot.ui catalog --trace /путь/к/edgectx_trace.jsonl
```

Путь доверенно задаётся при запуске процесса, через HTTP выбрать файл нельзя. Лаборатория раз в секунду читает только законченные JSONL-строки. Незаконченная последняя строка дожидается перевода строки; ошибка полной записи видна явно и не обновляет старые наблюдения. «Следовать за потоком» двигает курсор к последнему событию; ручной выбор времени удерживает прошлый момент. Ротация или перезапись файла создаёт отдельный прогон. Можно наблюдать до четырёх файлов; лимиты объёма и событий остаются теми же. Снимки входного контекста будут доступны, если агент запущен с `trace_context: true`.

## Камера

Для проектного `cam-mcp` есть отдельный проверенный адаптер снимка. Он вызывает только известный read-only `snapshot` по явному нажатию или включению обновления раз в 2 с; имя произвольного инструмента не даёт права его запускать. Изображение сохраняется в лабораторию вместе с MIME, размером, временем получения и метаданными возраста. Демонстрация запускает синтетическую сцену настоящего cam-mcp. Кадры LLM не отправляются. `robot-mcp.Look` не используется: такой вызов может двигать робота.

## Хранение и измерения

Лабораторные прогоны и подключения хранятся в памяти серверного процесса; для переноса и долговременного хранения используйте экспорт. В браузере ограниченно сохраняются привязки приборов, рецепты и карточки журнала. Лаборатория не читает произвольные пути по HTTP и не устанавливает зависимости автоматически.

Короткие RSS/CPU замеры относятся к одному PID агента на текущем хосте и реальному интервалу наблюдения. Это не восьмичасовой тест, не измерение Jetson, не энергия и не полный максимум за жизнь процесса. Usage локальной mock-модели — эвристическая оценка токенов. Отсутствующие измерения и стоимость обозначены «—»; происхождение и ограничения видны в интерфейсе.

В живом шлюзе на плате запуск лабораторных экспериментов отключён. Пульт сохраняет СТОП движения и постановку защёлки; произвольных команд приводам из нового пространства нет. Проигрывание трассы и изменение аналитического рецепта не изменяют устройство. Исполняемых контрольных точек для произвольного возврата во времени нет: новый эксперимент воспроизводит сценарий с начала.

## Визуальный подход и первоисточники

Приборная среда с общей временной позицией, разными цветами классов событий, коротким откликом на выбор и явным происхождением данных. Движение не подменяет отсутствующие измерения. Поддерживаются тёмная и светлая темы, мобильная горизонтальная прокрутка ленты и Reduce Motion.

- [Learnable Programming](https://worrydream.com/LearnableProgramming/): промежуточное состояние и ход вычисления должны быть видимыми.
- [Rerun Timeline](https://rerun.io/docs/reference/viewer/timeline): единый курсор для нескольких представлений данных.
- [Foxglove comparison mode](https://docs.foxglove.dev/docs/visualization/comparison-mode): совмещение независимых записей с явной шкалой.
- [Perfetto UI](https://perfetto.dev/docs/visualization/perfetto-ui): дорожки событий и разбор интервалов.
- [TouchDesigner operators](https://derivative.ca/UserGuide/Operator): типы данных и композиция преобразований.
- [Ink & Switch Potluck](https://www.inkandswitch.com/potluck/): постепенное превращение наблюдения в работающий инструмент.
- [W3C WoT TD 1.1](https://www.w3.org/TR/wot-thing-description11/): возможности, схемы и семантика устройства. Поле safe не является подтверждением физической безопасности действия.

Это источники проектных принципов. Научная новизна сочетания или универсальное распознавание неизвестного оборудования здесь не утверждаются.
