# Обзор проекта: идея, цели, что уже есть

Документ для человека или агента, который видит проект впервые. За 10 минут он даёт понять, что строим, зачем и
в каком всё состоянии. Подробности — в `HANDOFF.md`, план — в `docs/ROADMAP.md`, запуск на Windows —
в `docs/WINDOWS.md`.

## 1. Что это

Выпускная квалификационная работа (бакалавриат ИТМО, 09.03.01 «Информатика и вычислительная техника»).
Тема согласована с руководителем 06.10.2026: **«Разработка ИИ-агента для приложений граничного искусственного
интеллекта»**.

Суть. На одноплатном компьютере работает лёгкий ИИ-агент: Jetson Nano 4 ГБ на кафедре и в лаборатории.
- **Внешняя LLM** через OpenAI-совместимый API (RouterAI, модели класса «GPT mini») делает только смысловую работу. Сам агент — статический Go-бинарник на 10–30 МиБ.
- **Контекст пользователя:** история, профиль, правила.
- **Контекст оборудования:** что подключено, какие показания, какие события.
- **Связь с железом** — через **MCP-серверы**: датчики, исполнительные устройства, камера, робот.
- **Когда будить модель, агент решает сам** — по событиям и локальным правилам, а не по таймеру и не на каждое показание.

**Ключевая метрика — работа и экономность во времени, не надёжность.** Сколько вызовов LLM, токенов, рублей,
трафика, какие задержки, сколько памяти и CPU за рабочий день, в том числе при жёстких лимитах «слабой платы».
Безопасность и непрерывная работа — обязательные условия, но не цель исследования.

## 2. Два сценария

### 2.1. Датчики и исполнительные устройства (ядро ВКР)

Агент EdgeCtx на плате:
- узнаёт об оборудовании через **hw-mcp** (Linux sysfs: IIO, hwmon, 1-Wire, GPIO);
- о движении в кадре — через **cam-mcp** (детектор движения работает на самой плате, кадры в LLM не уходят);
- будит модель только на значимые ситуации: перегрев, протечка, вопрос пользователя;
- приводы включает через шлюз с проверками безопасности.

Сравнение — с аналогами PicoClaw и nanobot на одинаковых сценариях. NanoClaw руководитель назвал как пример,
но замерить его нельзя: Docker, Node ≥ 22, Claude Agent SDK.

### 2.2. Робот лаборатории NeuroChip (с 14.10.2026)

В лаборатории, где работает студент, есть демо-робот: Jetson Nano, ROS 2 Foxy, камера RealSense D435i,
лидар Hokuyo URG-04LX, STM32 с драйвером моторов. Оператор рисует рукой в воздухе жест:
- YOLOv5 находит кисть;
- траектория кисти превращается в картинку 28×28;
- спайковая сеть SNN распознаёт класс;
- робот выполняет манёвр.

Сверху стоит LLM-агент PicoClaw с MCP-сервером лаборатории.

Жалобы лаборатории:
- «после 3–4 жестов надо перезагружать»;
- задержки;
- «проблемы с запуском».

Задача: чтобы система работала **непрерывно, в реальном времени, без видимых перезапусков и безопасно** —
«помахал рукой — поехал». Это прикладной сценарий ВКР: быстрый локальный рефлекс плюс медленный LLM-агент сверху.

Что выяснили — `docs/neurobot/ANALYSIS.md` (с доказательствами по коду, журналам и презентации):
- в демо поток камеры молча умирает от первой ошибки;
- PicoClaw не поднимает упавший MCP-сервер;
- в MCP-сервере лаборатории команды движения объявлены дважды, и миллисекунды уходят в робота как секунды;
- лидар частично закрыт корпусом камеры — слепой сектор от −61° до +4° прямо по курсу;
- низкие препятствия лидар не видит.

## 3. Главный архитектурный принцип

**LLM не стоит в контуре реального времени.**
- Реакция на событие — локально, за миллисекунды: правило гейта у агента, рефлекс «жест → движение» у робота.
- LLM вызывается редко и по делу: вопрос пользователя, смысловая команда («проедь полметра»), объяснение тревоги.
- Для робота LLM в контуре жеста означала бы 2+ вызова и 3–6 секунд на каждый жест; так не делают ни в
  промышленных двухуровневых системах (Helix, GR00T N1, SayCan), ни у нас.

Для робота это значит:
- у `/cmd_vel` один писатель — узел безопасности `safety_gate`, который всегда шлёт явный «стоп»;
- каждый компонент — отдельный сервис systemd с проверкой готовности и автоперезапуском;
- агент работает через MCP командами уровня задачи и не может снять аварийную защёлку.

Тесты (15–16.10, Mac): Go — 59 пакетов, Python — 475 + 52 теста стенда, neurobot — 341 тест.

Проверено на цифровом двойнике (ориентир, не результат):
- от конца жеста до команды мотору 0,62–0,72 с; у лаборатории по видео около 2,5 с;
- 0 касаний в 18 сценариях безопасности из 21 — во всех, где робот физически мог остановиться;
- остановка после убийства узла безопасности — 0,44 с;
- весь стек робота в бюджете Jetson 4 ГБ занимает около 2,2 ГБ.
  Если на Jetson стоит рабочий стол GNOME, места почти не остаётся; рекомендация лаборатории — headless-образ.

## 5. Чего ещё нет (честно)

- **Ничего не проверено на железе:** ни плата, ни датчики, ни камера, ни робот, ни реальная LLM. Всё виртуально:
  ВМ, симулятор ядра, Gazebo, заглушка LLM.
- Финальные прогоны на двойнике: «их система как есть» против «после ремонта», 100 холодных стартов,
  1 час непрерывной работы, независимая приёмка. Это шаг W3, прерван — `docs/ROADMAP.md`.
- Этап Э3 для робота: исполнитель задач v2, robot-mcp с профилем «база», подключение EdgeCtx.
- Протокол экспериментов ВКР и сами эксперименты по метрике «во времени».
- Текст пояснительной записки. Глава 1 — к 15.01.2027.

## 6. Правила проекта (важно для любого агента)

1. **Честность чисел.** Всё, снятое на Mac, в ВМ, на заглушке LLM или под нагрузкой, — «ориентир, не результат».
   Результат ВКР — только прогон по протоколу на плате с реальной LLM. Отмечать [код] / [замер] / [оценка] /
   [допущение].
2. **Готовое не выдавать за своё:** Linux (cgroup, netem, gpio-sim), systemd, ROS 2, Gazebo, MCP SDK, PicoClaw,
   YOLO, snnTorch, код лаборатории. Не писать «никто не делал» — писать «в проверенных источниках не найдено».
3. **Деньги не тратить.** Ключ RouterAI выдан, но пока везде `bench/mockllm`. Ключи и токены нигде не записывать.
4. **Материалы лаборатории NeuroChip** (код, веса, журналы, презентация) **в публичный репозиторий не входят**:
   они лежат локально в `third_party/neurochip/` и передаются отдельно. Файлы `*.pt`/`*.pth` — непроверенный pickle:
   не загружать, кроме `snn_emnist_small.pth` с `weights_only=True` внутри ВМ.
5. **Удалять только в корзину,** перед крупной правкой — коммит или копия.
6. Общение со студентом — по-русски, коротко, без канцелярита.

## 7. С чего начать новому агенту

1. Прочитать этот файл, затем `docs/ROADMAP.md`. На Windows — сначала `docs/WINDOWS.md`.
2. `HANDOFF.md` — полный контекст. Он написан на Mac: пути `/Users/...` и команды `limactl` там маковские.
3. Для робота — `docs/neurobot/PLAN.md` (§13 — двойник, 4 ГБ, безопасность) и `docs/neurobot/ANALYSIS.md`.
4. README каталога — перед правкой любого компонента.
